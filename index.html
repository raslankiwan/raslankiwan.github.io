How I build

The speed comes from the agents. The quality comes from how the work is set up and checked.

01 Orchestrate

The strongest model on the riskiest work

02 Guide

Rules the agents can read

Every project carries a CLAUDE.md / AGENTS.md: the map, the commands, and the non-negotiables that can never be weakened to make a change land.

03 Verify

Nothing merges on trust
