# Raslan Kiwan — Personal website

Static portfolio hosted at https://raslankiwan.github.io/ using GitHub Pages.

## Update
Edit `index.html` and push to `main`. GitHub Pages publishes from the root of that branch. No build step or dependencies.

## Preview
Run `python3 -m http.server 4173` and open http://localhost:4173.

Only portfolio assets belong here. Project source and private repository material are not included.
